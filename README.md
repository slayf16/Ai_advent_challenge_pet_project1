# DeepChat — Ai Advent Challenge

Локальный веб-чат с выбором трёх облачных моделей: Liquid LFM 2.5 2.6B (бесплатно через OpenRouter), DeepSeek V4 Flash и V4 Pro. Браузер обращается к внутреннему серверному маршруту, а сервер передаёт запрос выбранному провайдеру. API-ключ остаётся на сервере.

## Возможности

- Обычный диалог и отдельный режим «Группа экспертов» по запросу пользователя.
- Три независимых ролевых ответа параллельно: диванный эксперт, эксперт-практик и аналитик.
- Своя прокручиваемая панель, статус, JSON и метрики у каждого эксперта; затем общий вывод в главном чате.
- Потоковая выдача текста с `stream: true`, остановка и сохранение частичных ответов.
- Отдельные сохраняемые чаты: каждый получает собственного агента с именем, моделью, системным промптом и всеми параметрами ответа.
- История чатов, черновики, экспертные запуски, JSON-снимки, метрики и повтор сохраняются локально и не смешивают контекст разных агентов.
- Редактируемый системный промпт, формат, лимит токенов и условие завершения ответа.
- Повтор исходного запроса с новыми параметрами без подмешивания предыдущих вариантов в его контекст.
- Живое время ответа, время до первого текстового фрагмента, средняя скорость, токены и расчёт стоимости в USD.
- Адаптивный тёмный интерфейс, Enter для отправки, Shift+Enter для переноса строки.
- WebMCP-инструмент `send_deepseek_message` в поддерживаемых окружениях.

## Задание 3: группа экспертов

1. Включите «Группа экспертов». Укажите тему, например «алгоритмы» или «анализ продаж».
2. При необходимости вставьте исходные данные: числа, таблицу или факты. Данные и контекст получат все три эксперта. Если данных нет, аналитик должен прямо указать ограничение.
3. В поле сообщения введите логическую, алгоритмическую или аналитическую задачу и нажмите «Запустить экспертов».
4. Три независимых запроса начнутся одновременно. Их ответы постепенно появятся в отдельных панелях. Это три ролевых запуска одной выбранной модели, а не три разных сервиса или настоящих специалиста.
5. После завершения всех трёх запросов главный ассистент получит исходную задачу, данные, полные ответы, статусы и информацию об обрезании. Он сравнит доводы и сформирует итог в основном чате.

Полные тексты ролевых инструкций и инструкции синтеза доступны в интерфейсе через «Посмотреть промпты ролей»; источник — `lib/experts.ts`. К каждой роли добавляются общая системная инструкция, выбранная тема и параметры ответа. Эксперты не получают ответы друг друга. Итоговый ассистент получает их как данные, а не как новые системные инструкции.

Если один эксперт завершился ошибкой, его частичный ответ и ошибка остаются видны; итоговый ассистент учитывает неполный состав. Если ни один эксперт не вернул текст, итоговый запрос не отправляется. Кнопка «Остановить» отменяет текущие запросы и не запускает последующий синтез. Частичные ответы сохраняются в интерфейсе, но не попадают в контекст обычных следующих сообщений как завершённые ответы.

Один успешный запуск группы — четыре обращения к API (платные для DeepSeek, бесплатные в пределах лимитов OpenRouter для Liquid): три эксперта и итог. Лимит токенов применяется отдельно к каждому. «Повторить запрос» повторяет исходный режим, тему, данные и контекст, используя текущие параметры; прошлые варианты остаются на экране для сравнения. Новое обычное сообщение продолжает историю завершённых ответов. «Новый диалог» создаёт отдельную сохранённую сессию с настройками `DEFAULT_SETTINGS`: DeepSeek V4 Flash, пустые текстовые поля и не заданные лимит токенов и температура; прежний чат, его параметры и результаты остаются в списке слева.

## Чаты и агенты

Кнопка «Новый диалог» создаёт чат «Новый чат» и нового `Agent` «Новый агент» с копией `DEFAULT_SETTINGS`, а не очищает предыдущий. В левой колонке можно вернуться к любому сохранённому чату: это удобный способ сравнить ответы разных настроенных агентов на одной задаче. У агента есть имя и полный набор параметров ответа; их изменение действует только на активный чат.

`Agent` из `lib/agent.ts` не является только моделью данных: обычный ответ, три экспертных ответа и итоговый синтез вызывают его метод `request()`. Агент принимает внедряемый `ChatTransport`; браузерный транспорт обращается только к `/api/chat`, поэтому ключи поставщиков по-прежнему остаются на сервере.

Сессии сохраняются в `localStorage` текущего браузера. В них входят сообщения, настройки агента, черновик, режим экспертов, результаты, метрики и данные повторного запуска. Незавершённый поток после перезагрузки помечается остановленным, поскольку его нельзя безопасно продолжить. В этом варианте нет синхронизации между браузерами или пользователями; чтобы удалить локальную историю, очистите данные сайта в браузере.

Новый чат начинается с DeepSeek V4 Flash, пустых текстовых параметров и без лимита токенов, температуры или условия завершения. «Очистить параметры» возвращает активный чат к этим значениям, сохраняя выбранную в нём модель.

- **Модель:** Liquid LFM 2.5 2.6B — «Маленькая · бесплатная», облачная модель через OpenRouter для сравнения. V4 Flash — «Слабее · дешевле» для повседневных задач; V4 Pro — «Сильнее · дороже» для сложного анализа и программирования. Это сравнительный ориентир, качество зависит от задачи. Выбор применяется к обычному чату, трём экспертам и синтезу. Повтор и очистка параметров используют выбранную в активном чате модель; новый диалог начинается с Flash. Во время ответа выбор заблокирован. Модель каждого запроса сохраняется в его метриках, поэтому смена модели не пересчитывает историю по новому тарифу.

- **Системный промпт:** произвольная инструкция до 8 000 символов. В группе экспертов общий текст вместе с добавленной ролью должен поместиться в этот лимит; при превышении интерфейс предложит сократить инструкцию до отправки запросов.
- **Формат:** описание до 2 000 символов, например «Три пункта с примерами». Это инструкция модели, а не принудительный JSON-режим.
- **Максимум токенов:** целое число 1–4 096 или пустое поле для лимита DeepSeek по умолчанию. При заданном лимите сервер передаёт `thinking: { "type": "disabled" }`, чтобы бюджет относился к видимому ответу. `finish_reason: "length"` сопровождается предупреждением об обрезании.
- **Завершение:** без условия, инструкция до 2 000 символов либо стоп-строка до 200 символов. API исключает стоп-строку из ответа; не используйте маркер, который может встретиться в нужном тексте. Пробелы в непустой стоп-строке сохраняются.

- **Температура:** число от 0 до 2 включительно, в том числе дробное. Меньше — более предсказуемые ответы, больше — более разнообразные. Пустое поле не добавляет `temperature` в API-запрос. При заданном значении сервер передаёт `thinking: { "type": "disabled" }`, поскольку [режим рассуждений DeepSeek игнорирует температуру](https://api-docs.deepseek.com/guides/thinking_mode/). Настройка применяется к обычным ответам, всем экспертам и итоговому синтезу; повтор запроса использует текущее значение. Значение видно в JSON запроса.

Пустые настройки в обычном чате не добавляют системного сообщения, `max_tokens`, `temperature`, `thinking` или `stop`. Запрос содержит `model`, `messages`, `stream: true` и `stream_options: { "include_usage": true }`.

JSON-панель показывает точное тело последней попытки обращения к выбранному провайдеру сразу после получения серверного события `request`. При параллельных вызовах общий снимок соответствует последнему полученному событию, а каждая экспертная панель хранит собственный снимок. После старта итогового запроса общий снимок обновляется на него. При сетевой ошибке наличие JSON не подтверждает доставку. Локальные ошибки и отсутствие ключа не создают снимка. Заголовок авторизации в JSON не входит.

## Метрики

Метрики есть у каждого запроса и для всего диалога. Раскрытие «Токены и расчёт стоимости» показывает входные/выходные токены, cache hit/miss, reasoning (если API его сообщил), формулу и ссылку на тариф.

- Время и задержка до первого текстового фрагмента измеряются на клиенте. Таймер обновляется во время запроса.
- Средняя скорость = `completion_tokens / полное время запроса в секундах`. Время включает сеть, ожидание и возможное скрытое рассуждение. Это не мгновенная скорость видимых токенов.
- Токены берутся из финального `usage` API, а не считаются по тексту или количеству чанков. При обрыве статистика может отсутствовать: UI показывает «Нет данных» и помечает общий расход как частичный.
- Стоимость — расчёт по официальному тарифу выбранной модели, проверенному 6 сентября 2026 года, а не выписка из баланса. Для Flash за миллион токенов вне пика: cache hit $0.007, cache miss $0.22, output $0.66; в пик: $0.014, $0.44, $1.32. Для Pro вне пика: $0.022, $0.66, $1.98 соответственно; в пик: $0.044, $1.32, $3.96. Пиковые окна: 01:00–04:00 и 06:00–10:00 UTC с понедельника по пятницу; выходные — вне пика. Тариф выбирается по времени начала запроса на клиенте; на границе окна или при неточных часах фактическое списание может отличаться.
- При отсутствии корректной cache-разбивки показывается диапазон стоимости. Общая сумма включает только запросы с полученной статистикой.
- Общее время — от первого до последнего запроса; для всего диалога оно включает пользовательские паузы. Параллельные интервалы не суммируются.

Для Liquid LFM 2.5 2.6B Free входные и выходные токены бесплатны: при получении usage стоимость точно $0, даже без cache-разбивки. Без usage статистика остаётся неизвестной. Платные модели и бесплатная Liquid корректно суммируются в общем расходе. Источник: [OpenRouter Liquid LFM 2.5 2.6B](https://openrouter.ai/liquid/lfm-2.5-2.6b:free).

Тарифы находятся в `lib/chat-metrics.ts`; при изменении цен их следует обновить по [официальной странице DeepSeek](https://api-docs.deepseek.com/quick_start/pricing).

## Локальный запуск и проверки

```bash
npm install
```

Создайте `.env.local` на основе `.env.example`; в PowerShell:

```powershell
Copy-Item .env.example .env.local
```

Запишите свой ключ только в `.env.local`:

```dotenv
DEEPSEEK_API_KEY=your_real_deepseek_api_key
```

```bash
npm run dev       # откройте Local URL из терминала
npm test          # тесты с подменой API, без ключа и платных запросов
npm run lint
npx tsc --noEmit --incremental false

npm start         # запуск production-сборки локально
```

## Подключение бесплатной Liquid через OpenRouter

В существующую `.env.local` добавьте ключ OpenRouter (пустая переменная уже подготовлена):

```dotenv
OPENROUTER_API_KEY=your_openrouter_api_key
```

Сохраните DEEPSEEK_API_KEY для Flash/Pro. Каждый ключ требуется только для своего провайдера. После изменения переменных перезапустите локальный сервер, если он не подхватил их автоматически. Не публикуйте ключи.

Выберите «Liquid LFM 2.5 2.6B — Маленькая · бесплатная». Все параметры, эксперты и повтор доступны. У Liquid режим рассуждений обязателен: поля отключения reasoning и thinking не отправляются. Лимит токенов включает рассуждения; слишком маленький лимит может исчерпаться до видимого ответа. Поддержка настроек зависит от обслуживающего провайдера. При отсутствии ключа или недоступности бесплатной модели интерфейс показывает ошибку; платный вариант автоматически не включается. Бесплатный аккаунт OpenRouter имеет лимиты (на момент проверки — 50 запросов в день и 20 в минуту); группа использует 4 запроса. [Актуальные лимиты](https://openrouter.ai/docs/api_reference/limits).

## API приложения

`POST /api/chat` принимает:

```json
{
  "messages": [{ "role": "user", "content": "Объясни алгоритм" }],
  "settings": {
    "model": "deepseek-v4-flash",
    "systemPrompt": "Объясняй начинающему программисту.",
    "format": "Три пункта",
    "maxTokens": 512,
    "temperature": 0.7,
    "stopMode": "none",
    "stopInstruction": "",
    "stopSequence": ""
  }
}
```

`settings` и отдельные поля необязательны. `settings.model` принимает только `deepseek-v4-flash`, `deepseek-v4-pro` и `liquid/lfm-2.5-2.6b:free`; при отсутствии используется Flash. Неизвестная модель возвращает HTTP 400 до обращения к провайдеру. Сервер принимает 1–30 сообщений ролей user/assistant, каждое до 12 000 символов, последнее — user. Обычный клиент передаёт последние 29 сообщений. В экспертном режиме данные добавляются отдельным сообщением. Для синтеза полные ответы делятся на допустимые фрагменты; старый контекст сокращается под них. Если даже ответы не помещаются, синтез не отправляется, UI просит уменьшить лимит; ответы остаются в панелях и не обрезаются молча.

Успех: `Content-Type: text/event-stream; charset=utf-8`. Каждое событие заканчивается пустой строкой:

```text
event: request
data: {"requestJson":"{...}"}

event: delta
data: {"content":"Первый фрагмент"}

event: done
data: {"finishReason":"stop","usage":{"prompt_tokens":100,"completion_tokens":20,"total_tokens":120},"model":"deepseek-v4-flash"}

```

После начала потока ошибка передаётся событием `error` с `{ "error": "Описание" }`; до начала — JSON и HTTP-статус. Все ответы имеют `Cache-Control: no-store`. Сервер разбирает UTF-8, границы чанков, CRLF, комментарии и `[DONE]`; тайм-аут приложения 5 минут (300 000 мс) охватывает каждый запрос и чтение потока, отдельно для каждого эксперта и синтеза. До начала потока тайм-аут возвращает HTTP 504, после начала — SSE error с явным текстом «Таймаут приложения». Частичный ответ сохраняется. HTTP 408/504 провайдера обозначаются отдельно. Обрыв раньше этого времени может быть связан с сетью или провайдером; само время обрыва не определяет причину. Отмена клиента прекращает upstream. Usage-поля отсутствующих данных не заменяются выдуманными значениями.

Маршрут выбирает фиксированный адрес и серверный ключ по разрешённому ID модели: DeepSeek → https://api.deepseek.com/chat/completions / DEEPSEEK_API_KEY; Liquid → https://openrouter.ai/api/v1/chat/completions / OPENROUTER_API_KEY. Ключ одного провайдера не передаётся другому. Произвольные модели и URL не принимаются, автоматического перехода на платные модели нет. Клиент никогда не передаёт API-ключ. Не коммитьте `.env*` (кроме примера), секреты или серверные логи. При публикации ключ задаётся серверной переменной/секретом платформы.

Документация API: [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/).
