# DeepChat — Ai Advent Challenge

Локальный веб-чат с DeepSeek V4 Flash. Браузер обращается к внутреннему серверному маршруту, а сервер передаёт запрос DeepSeek. API-ключ остаётся на сервере.

## Возможности

- Обычный диалог и отдельный режим «Группа экспертов» по запросу пользователя.
- Три независимых ролевых ответа параллельно: диванный эксперт, эксперт-практик и аналитик.
- Своя прокручиваемая панель, статус, JSON и метрики у каждого эксперта; затем общий вывод в главном чате.
- Потоковая выдача текста с `stream: true`, остановка и сохранение частичных ответов.
- Редактируемый системный промпт, формат, лимит токенов и условие завершения ответа.
- Повтор исходного запроса с новыми параметрами без подмешивания предыдущих вариантов в его контекст.
- Живое время ответа, время до первого текстового фрагмента, средняя скорость, токены и расчёт стоимости в USD.
- Адаптивный тёмный интерфейс, Enter для отправки, Shift+Enter для переноса строки.
- WebMCP-инструмент `send_deepseek_message` в поддерживаемых окружениях.

## Задание 3: группа экспертов

1. Включите «Группа экспертов». Укажите тему, например «алгоритмы» или «анализ продаж».
2. При необходимости вставьте исходные данные: числа, таблицу или факты. Данные и контекст получат все три эксперта. Если данных нет, аналитик должен прямо указать ограничение.
3. В поле сообщения введите логическую, алгоритмическую или аналитическую задачу и нажмите «Запустить экспертов».
4. Три независимых запроса начнутся одновременно. Их ответы постепенно появятся в отдельных панелях. Это три ролевых запуска одной модели DeepSeek, а не три разных сервиса или настоящих специалиста.
5. После завершения всех трёх запросов главный ассистент получит исходную задачу, данные, полные ответы, статусы и информацию об обрезании. Он сравнит доводы и сформирует итог в основном чате.

Полные тексты ролевых инструкций и инструкции синтеза доступны в интерфейсе через «Посмотреть промпты ролей»; источник — `lib/experts.ts`. К каждой роли добавляются общая системная инструкция, выбранная тема и параметры ответа. Эксперты не получают ответы друг друга. Итоговый ассистент получает их как данные, а не как новые системные инструкции.

Если один эксперт завершился ошибкой, его частичный ответ и ошибка остаются видны; итоговый ассистент учитывает неполный состав. Если ни один эксперт не вернул текст, итоговый запрос не отправляется. Кнопка «Остановить» отменяет текущие запросы и не запускает последующий синтез. Частичные ответы сохраняются в интерфейсе, но не попадают в контекст обычных следующих сообщений как завершённые ответы.

Один успешный запуск группы — четыре платных обращения: три эксперта и итог. Лимит токенов применяется отдельно к каждому. «Повторить запрос» повторяет исходный режим, тему, данные и контекст, используя текущие параметры; прошлые варианты остаются на экране для сравнения. Новое обычное сообщение продолжает историю завершённых ответов. «Новый диалог» очищает сообщения, результаты, JSON и метрики, сохраняя настройки, тему и введённые данные.

## Параметры и системный промпт

Все поля по умолчанию пустые. «Очистить параметры» сбрасывает системный промпт, формат, лимит и завершение, сохраняя чат.

- **Системный промпт:** произвольная инструкция до 8 000 символов. В группе экспертов общий текст вместе с добавленной ролью должен поместиться в этот лимит; при превышении интерфейс предложит сократить инструкцию до отправки запросов.
- **Формат:** описание до 2 000 символов, например «Три пункта с примерами». Это инструкция модели, а не принудительный JSON-режим.
- **Максимум токенов:** целое число 1–4 096 или пустое поле для лимита DeepSeek по умолчанию. При заданном лимите сервер передаёт `thinking: { "type": "disabled" }`, чтобы бюджет относился к видимому ответу. `finish_reason: "length"` сопровождается предупреждением об обрезании.
- **Завершение:** без условия, инструкция до 2 000 символов либо стоп-строка до 200 символов. API исключает стоп-строку из ответа; не используйте маркер, который может встретиться в нужном тексте. Пробелы в непустой стоп-строке сохраняются.

Пустые настройки в обычном чате не добавляют системного сообщения, `max_tokens`, `thinking` или `stop`. Запрос содержит `model`, `messages`, `stream: true` и `stream_options: { "include_usage": true }`.

JSON-панель показывает точное тело последней попытки обращения к DeepSeek сразу после получения серверного события `request`. При параллельных вызовах общий снимок соответствует последнему полученному событию, а каждая экспертная панель хранит собственный снимок. После старта итогового запроса общий снимок обновляется на него. При сетевой ошибке наличие JSON не подтверждает доставку. Локальные ошибки и отсутствие ключа не создают снимка. Заголовок авторизации в JSON не входит.

## Метрики

Метрики есть у каждого запроса и для всего диалога. Раскрытие «Токены и расчёт стоимости» показывает входные/выходные токены, cache hit/miss, reasoning (если API его сообщил), формулу и ссылку на тариф.

- Время и задержка до первого текстового фрагмента измеряются на клиенте. Таймер обновляется во время запроса.
- Средняя скорость = `completion_tokens / полное время запроса в секундах`. Время включает сеть, ожидание и возможное скрытое рассуждение. Это не мгновенная скорость видимых токенов.
- Токены берутся из финального `usage` API, а не считаются по тексту или количеству чанков. При обрыве статистика может отсутствовать: UI показывает «Нет данных» и помечает общий расход как частичный.
- Стоимость — расчёт по официальному тарифу DeepSeek V4 Flash, проверенному 5 сентября 2026 года, а не выписка из баланса. За миллион токенов вне пика: cache hit $0.007, cache miss $0.22, output $0.66; в пик: $0.014, $0.44, $1.32. Пиковые окна: 01:00–04:00 и 06:00–10:00 UTC. Тариф выбирается по времени начала запроса на клиенте; на границе окна или при неточных часах фактическое списание может отличаться.
- При отсутствии корректной cache-разбивки показывается диапазон стоимости. Общая сумма включает только запросы с полученной статистикой.
- Общее время — от первого до последнего запроса; для всего диалога оно включает пользовательские паузы. Параллельные интервалы не суммируются.

Тарифы находятся в `lib/chat-metrics.ts`; при изменении цен их следует обновить по [официальной странице DeepSeek](https://api-docs.deepseek.com/quick_start/pricing).

```text
app/

  expert-panel.tsx            # три отдельных окна ответов
  request-metrics.tsx         # живые и итоговые метрики, раскрытие формулы
  response-settings.tsx       # редактор системного промпта, параметры, JSON
  ui/                         # готовые UI-примитивы

  chat-request.ts             # контракт, валидация, сборка тела API
  chat-stream.ts              # клиентский SSE-парсер и streamChat
  chat-metrics.ts             # метрики и тарифы
  experts.ts                  # промпты ролей, подготовка контекста синтеза
  utils.ts                    # UI-утилиты
tests/
  chat-api.test.mjs            # сервер, SSE, ошибки и отмена
  chat-stream.test.mjs         # клиентский потоковый протокол
  chat-request.test.mjs        # параметры и системный промпт
  chat-metrics.test.mjs        # стоимость, cache, интервалы
  orchestration.test.mjs       # параллельность, синтез, повтор, отмена, контекст
.openai/hosting.json           # сохранённая конфигурация Sites
.env.example                  # имя переменной без настоящего ключа
```

Стек: TypeScript, React 19, vinext/Vite, Tailwind 4, shadcn/ui, Cloudflare Workers/Wrangler. Требуется Node.js 22.13.0+.

## Локальный запуск и проверки

```bash
npm install
```

Создайте `.env.local` на основе `.env.example`; в PowerShell:

```powershell
Copy-Item .env.example .env.local
```

Запишите свой ключ только в `.env.local`:

```dotenv
DEEPSEEK_API_KEY=your_real_deepseek_api_key
```

```bash
npm run dev       # откройте Local URL из терминала
npm test          # тесты с подменой API, без ключа и платных запросов
npm run lint
npx tsc --noEmit --incremental false
npm run build
npm start         # запуск production-сборки локально
```

## API приложения

`POST /api/chat` принимает:

```json
{
  "messages": [{ "role": "user", "content": "Объясни алгоритм" }],
  "settings": {
    "systemPrompt": "Объясняй начинающему программисту.",
    "format": "Три пункта",
    "maxTokens": 512,
    "stopMode": "none",
    "stopInstruction": "",
    "stopSequence": ""
  }
}
```

`settings` и отдельные поля необязательны. Сервер принимает 1–30 сообщений ролей user/assistant, каждое до 12 000 символов, последнее — user. Обычный клиент передаёт последние 29 сообщений. В экспертном режиме данные добавляются отдельным сообщением. Для синтеза полные ответы делятся на допустимые фрагменты; старый контекст сокращается под них. Если даже ответы не помещаются, синтез не отправляется, UI просит уменьшить лимит; ответы остаются в панелях и не обрезаются молча.

Успех: `Content-Type: text/event-stream; charset=utf-8`. Каждое событие заканчивается пустой строкой:

```text
event: request
data: {"requestJson":"{...}"}

event: delta
data: {"content":"Первый фрагмент"}

event: done
data: {"finishReason":"stop","usage":{"prompt_tokens":100,"completion_tokens":20,"total_tokens":120},"model":"deepseek-v4-flash"}

```

После начала потока ошибка передаётся событием `error` с `{ "error": "Описание" }`; до начала — JSON и HTTP-статус. Все ответы имеют `Cache-Control: no-store`. Сервер разбирает UTF-8, границы чанков, CRLF, комментарии и `[DONE]`; тайм-аут 90 секунд охватывает запрос и чтение потока. Отмена клиента прекращает upstream. Usage-поля отсутствующих данных не заменяются выдуманными значениями.

Маршрут использует серверный ключ для `https://api.deepseek.com/chat/completions`. Клиент никогда не передаёт API-ключ. Не коммитьте `.env*` (кроме примера), секреты или серверные логи. При публикации ключ задаётся серверной переменной/секретом платформы.

Документация API: [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/).
